
# 基金溢价率计算工具使用说明

## 方案一：浏览器直接使用（无需安装任何软件，现价为估算值）

### 使用步骤：

1. **下载文件**：将 `index.html` 文件下载到你的电脑
2. **打开文件**：双击 `index.html` 文件，会在浏览器中打开
3. **开始使用**：
   - 输入基金代码（如 161725）
   - 点击"添加"按钮
   - 即可看到基金的估算溢价率

### 注意事项：
- ⚠️ 此方案的"现价"为天天基金的**估算净值**，不是场内实时价格
- 溢价率是基于估算值计算的，可能与实际交易价格有差异
- 适合快速了解溢价率趋势

---

## 方案二：使用Python后端（获取真实场内价格，推荐）

此方案可以获取真实的场内交易价格和溢价率，数据更准确！

### 前置要求：

1. **安装Python**（如果还没有）：
   - 访问 https://www.python.org/downloads/
   - 下载并安装Python
   - 安装时勾选 "Add Python to PATH"

2. **安装必要的库**：
   打开终端（Mac：终端；Windows：命令提示符），运行：
   ```bash
   pip install flask flask-cors akshare
   ```

### 使用步骤：

1. **下载所有文件**：
   - `server.py` - 后端服务器
   - `index.html` - 前端页面

2. **启动服务器**：
   打开终端，进入文件所在目录，运行：
   ```bash
   python server.py
   ```
   你会看到：`访问地址: http://localhost:5000`

3. **打开浏览器**：
   - 访问 `http://localhost:5000`
   - 开始使用！

### 功能特点：
- ✅ 使用AKShare获取东方财富真实数据
- ✅ 实时场内交易价格
- ✅ 准确的溢价率计算
- ✅ 支持LOF和ETF
- ✅ 数据延迟约3-5秒

## 常见问题

### Q: 为什么两种方案数据不一样？
A: 方案一的"现价"是估算净值，方案二的是真实场内交易价格。

### Q: 方案二需要安装Python吗？
A: 是的，需要先安装Python和相关库。

### Q: 可以在手机上使用吗？
A: 方案一可以在手机浏览器直接打开；方案二需要电脑上先运行服务器。

### Q: 数据会保存吗？
A: 会的，你添加的基金列表会保存到浏览器本地，刷新页面不会丢失。

## 技术说明

### 数据来源：
- **方案一**：天天基金网估算数据（免费，限制：不是实时场内价格）
- **方案二**：东方财富网通过AKShare获取（更准确）

### 溢价率计算公式：
```
溢价率 = (现价 - 最新净值) / 最新净值 × 100%
```

- **正溢价**：现价 &gt; 净值，红色显示
- **负溢价**：现价 &lt; 净值，绿色显示
